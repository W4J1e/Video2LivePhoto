# Video2LivePhoto - 实况照片生成器

一个简单、美观且隐私安全的纯静态网页工具，用于将视频转换或与图片合并导出为实况照片（Live Photo），并且保留原视频声音。

支持从微博、抖音等平台下载的短视频与照片重新合并，使其能被安卓手机（如小米）、Windows 10/11 照片应用以及群晖（Synology Photos）正确识别。

## ✨ 功能特性

- **🚀 纯客户端处理**：所有视频处理和图片合成均在浏览器本地完成，无需上传服务器，保护隐私且速度极快。
- **📱 多格式支持**：
  - **Google Motion Photo**：生成的单张 JPG 图片支持在安卓系统（如小米相册）及谷歌相册中直接播放。
  - **Apple Live Photo (兼容模式)**：生成包含同名 JPG 和 MOV 的压缩包，解决 Windows 照片应用和群晖无法识别的问题。
- **🎬 视频剪辑**：支持通过滑块轻松截取视频中所需的片段。
- **🖼️ 自定义封面**：可以自动提取视频首帧作为封面，也支持上传本地照片作为实况图的静态封面。
- **🎨 现代 UI**：基于 Tailwind CSS 构建的简洁、响应式界面，支持移动端操作。

## 🛠️ 安装与运行

由于本项目使用了 **ES Modules** 模块化开发，浏览器安全策略要求必须在服务器环境下运行。

### 方法 A：VS Code 插件（推荐）
1. 使用 VS Code 打开本项目文件夹。
2. 安装 **Live Server** 插件。
3. 点击右下角的 `Go Live` 按钮。

### 方法 B：命令行运行
如果你安装了 Node.js，可以直接运行：
```bash
npx serve .
```

## 📖 使用指南

1. **上传视频**：将你想转换的视频文件拖入或点击上传。
2. **选择范围**：调整“开始时间”和“结束时间”滑块，截取最精彩的片段（建议 3 秒以内）。
3. **设置封面**：默认使用视频第一帧，你也可以点击“上传照片”选择一张高质量图片作为实况图的静态封面。
4. **选择格式**：
   - **自动选择/Google**：适合安卓用户，生成单个 JPG 文件。
   - **Apple**：适合 Windows 或群晖用户，下载后请解压。
5. **生成与下载**：点击“生成动态照片”，处理完成后预览效果并下载。
